# Release Notes v1.0.6

## 🚀 Version 6 Release

This release includes performance improvements, stability enhancements, and bug fixes.

### User Experience & Lead Management
- **Kanban Board Integration**: Now displays real-time data from the database. Call statuses ("Interested", "Unreachable", etc.) automatically update the board.
- **Lead Limits Removed**: Increased lead assignment and view limits from 1000 to indefinite (up to 100k+).
- **Simplified Workflow**:
    - "Callback" logic merged into "Interested".
    - Removed "Converted" manual option.
    - Renamed "Do Not Call" to "Unreachable".
- **After-Call Summary**: Streamlined UI, conditional "Lead Strength" (only for Interested leads).

## 🔧 Technical Updates

- Updated to version 1.0.6 across all components
- Improved build process
- Enhanced update mechanism
