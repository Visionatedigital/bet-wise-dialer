## RAW FEATURE DATA

### Application Overview
- **App name:** BetSure Dialer (Bangbet Dialer)
- **Purpose:** A professional call-centre dialer for betting platform customer engagement — outbound calling, lead management, and performance tracking
- **Deployment:** Desktop application (Windows/Mac) and mobile (iOS/Android)
- **Core mission:** Help sales teams re-engage dormant and semi-active betting customers, drive deposits, and convert new customers through structured outbound calling

---

### Role System
Country Managers hold the **Management** role. They have visibility across their entire country's agent team. Above them sits Admin (head office); below them are individual Agents.

Permissions granted to the Management role:
- View and manage all agents in their country
- Import and distribute leads
- Monitor agent performance in real time
- Generate and export team reports
- Manage campaigns
- Approve nothing at system level (that sits with Admin)

---

### Dashboard — Analytics Home
When a Country Manager logs in they land on a **team analytics dashboard**. Key information visible at a glance:
- Total calls made by the team (today / this week / this month)
- Team connect rate (calls answered ÷ calls made)
- Team conversion count and conversion rate
- Total revenue (deposits) generated by the team
- Top-performing agents
- Agent status breakdown (how many online, on-call, on break, offline)
- Period filter: today, yesterday, last 7 days, last 30 days, this month, custom range

---

### Lead Import
**Location:** Manage Leads → Import Leads

Country managers are responsible for feeding new lead data into the system. The import flow:
1. Export a customer list from the betting platform (Excel or CSV)
2. Upload the file inside the app — the system accepts Chinese or English column headers automatically
3. The system intelligently **segments every lead** before import:
   - **VIP** — high-deposit, frequent bettors
   - **Semi-active** — moderate engagement, recent activity
   - **Dormant** — lapsed customers who need re-engagement
4. Segmentation is based on: deposit amount, bet frequency, last login date, VIP flag
5. After import, leads are distributed to agents (see Lead Distribution below)
6. Import history is saved — you can review every batch ever uploaded

---

### Lead Distribution
**Location:** Manage Leads → Distribute

After import, leads must be assigned to agents:
- Set how many leads each agent receives
- The system distributes evenly or by manager-defined rules
- Unassign all leads and redistribute at any time (useful after team changes or when recycling leads)
- View how many leads each agent currently holds

### Agent Monitoring (Live)
**Location:** Agent Monitoring

Real-time visibility into what every agent is doing right now:
- **Status per agent:** On-Call, Online, On Break, Offline — with a live colour indicator
- **Per-agent metrics:** assigned leads, calls made today, connects, conversions, revenue
- **Quality score** per agent — automatically calculated from a 5-point call quality checklist:
  1. Proper greeting
  2. Customer verification
  3. Active listening
  4. Product knowledge
  5. Closing summary
- Drill into any agent to see a detail sheet
- Export the monitoring snapshot

This screen is the manager's "floor view" — equivalent to walking the sales floor and checking in on each agent.

Deep-dive team performance with full filtering:
- **Filters:** agent, date range, campaign

  - Total calls (team and individual)

  - Conversion count and rate
  - Revenue generated
  - Daily/weekly trend graphs

### Reports
**Location:** Reports (also Management Reports)

Generate, save, and share formal reports:
- **Report types:** Agent performance, team summary, call transactions, conversion attribution, revenue, lead distribution, campaign performance
- **Date range:** flexible — today through custom range
- **Export formats:** PDF, Excel (.xlsx), Word (.docx)

### Refresh Performance (Performance Sync)
**Location:** Manage Leads → Refresh Performance

After agents finish calling, customers may go on to place bets or make deposits — sometimes hours later. Refresh Performance pulls updated data from the betting platform and links post-call deposits back to the agents who made the calls. This gives accurate **conversion attribution** — so managers know which agent drove which revenue.

Use this after a calling campaign wraps up, or at the end of each day.

### Promising Leads
**Location:** Promising Leads

A filtered view of leads that are progressing through the sales funnel:
- Lifecycle stages shown: **Interested → Follow-up → Converting → Converted**
- After Refresh Performance runs, converted leads show their attributed deposit amounts
- Use this page to see which leads are close to converting and ensure agents are following up

### Campaign Management
**Location:** Campaigns

Campaigns organise calling activity around a specific goal or audience:
- **Create campaigns** with a name, description, target segment, start/end dates, and targets (calls, conversions, revenue)
- **Status:** Active, Paused, Completed
- **Campaign metrics:** leads assigned, calls made, conversions achieved, deposits generated
- **Pause/resume** campaigns at any time
- AI generates a pitch script for each campaign — agents see this guidance in real time during calls
- Leads can be filtered and assigned by campaign

- Monitor agent quality and performance across any period

### Key Workflows for Country Managers

**Weekly rhythm:**
1. Monday — Import fresh leads from the betting platform; distribute to agents
2. Daily — Check the live monitor each morning; review who is online and performing
3. Daily — End of day, run Refresh Performance to capture overnight deposits
4. Friday — Generate weekly team report; export to PDF or Excel for head office
5. Ongoing — Review Promising Leads to ensure follow-ups are happening
6. Monthly — Full performance review with agent comparison; export Excel for HR or payroll

**Responding to underperformance:**
1. Open Performance → filter to the underperforming agent
2. Check connect rate — if low, the lead data or call times may need adjusting
3. Check quality score on the Monitor page — if low, coach on the checklist criteria
4. Check conversion rate — if connects are fine but no conversions, review the pitch (Campaigns page)

### Data Glossary (for the polished document, define these terms)

| Term | Definition |
|---|---|
| Connect Rate | Percentage of dials where the customer answered |
| Conversion | A lead who made a deposit after being called |
| Conversion Rate | Percentage of connected calls that resulted in a deposit |

| Lifecycle Stage | Where the lead sits in the funnel: New → Called → Interested → Follow-up → Converting → Converted → Dead |
| Quality Score | 0–100 score based on how well an agent followed the 5-point call quality checklist |
| Refresh Performance | Sync that links post-call deposits back to the agent who made the call |
| Segment | Classification of a lead: VIP, Semi-Active, or Dormant |
